Privacy

Last updated 28 October 2026.

The lookup tool runs entirely in your browser. When the page opens it downloads one data file, assets/tool.json, from this same site. Every estimate is computed on your device from that file.

Nothing you choose (hub, airline, hour, month, layover or walking time) is sent anywhere. There is no server behind the tool, no account, no cookie, no analytics and no third-party script or font. Fonts are served from this site.

The site is hosted on GitHub Pages. GitHub receives the ordinary web request for each file, as it does for any website it hosts, and handles that under its own privacy statement. This project keeps no logs and has nothing to delete. Questions go to the issue tracker.
